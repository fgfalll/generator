# Генератор Документів v4.5

![Версія](https://img.shields.io/badge/version-4.5-blue.svg) ![Python](https://img.shields.io/badge/python-3.9%2B-blue.svg) ![Framework](https://img.shields.io/badge/framework-PyQt6-green.svg) ![Ліцензія](https://img.shields.io/badge/license-MIT-lightgrey.svg)

**Генератор Документів** — це потужний настільний застосунок для автоматизації створення документів Word (`.docx`) на основі табличних даних з файлів Excel (`.xlsx`) або CSV. Програма розроблена для значного прискорення робочих процесів, де потрібно генерувати велику кількість однотипних документів, таких як довідки, витяги, описи справ, листи та інші.

Версія 4.5 привносить **повністю переосмислений інтерфейс у стилі MS Office Ribbon**, просунуту систему фільтрації та безшовний інструментарій для управління даними (трансформації, контекстні меню).

## Основні Можливості

-   **Пакетна генерація:** Створюйте сотні унікальних документів за лічені хвилини на основі одного файлу даних та набору шаблонів.
-   **Сучасний Ribbon-інтерфейс:** Зручне групування інструментів (Файл, Колонки, Фільтрація, Трансформації) у стилі сучасних офісних програм.
-   **Потужні інструменти трансформації даних (Вбудовані у таблицю):**
    -   **Розділення колонок:** Легко розділяйте складні поля (напр., "Прізвище Ім'я По батькові") на окремі колонки за допомогою візуального майстра з попереднім переглядом.
    -   **Менеджер колонок:** Додавайте, перейменовуйте, дублюйте, видаляйте та сортуйте колонки у зручному вікні-менеджері.
    -   **Контекстні меню:** Мультифункціональне меню, доступне за правим кліком по клітинках або лівим кліком по заголовкам таблиці.
-   **Просунута Фільтрація:**
    -   13+ логічних умов (містить, дорівнює, більше, менше, регулярний вираз, порожнє тощо).
    -   Логіка І/АБО (AND/OR) для побудови складних запитів.
    -   Візульний індикатор 🔍 фільтрації безпосередньо в заголовках колонок.
-   **Об'єднання та Співставлення:**
    -   Візуальне "Співставлення" колонок таблиці з полями у вашому `.docx` шаблоні. Функція авто-маппінгу автоматично знайде точні збіги.
    -   Злиття декількох вибраних колонок в одну за вказаним роздільником.
-   **Керування шаблонами та Директоріями:** 
    -   Ієрархічне відображення шаблонів з підтримкою підпапок (QTreeWidget).
    -   "Розумний імпорт" директорій: копіювання файлів із збереженням вкладеної структури.
    -   Візуальне підсвічування активного редагованого шаблону в списку.
    -   Контекстне меню: швидке відкриття шаблону у Word або відкриття його папки у Провіднику.
-   **Гнучке налаштування балів (Чисел прописом):** Автоматична генерація суми прописом (напр., `сто вісімдесят п'ять`) для числових даних із призначенням унікальних тегів.
-   **Глобальний обробник помилок:** Замість "тихих" вильотів, програма перехоплює непередбачувані помилки та показує візуальне вікно (QMessageBox) з детальним описом стеку (Traceback).

## Встановлення та запуск

**Вимоги:** Python 3.9 або новіше.

1.  **Клонуйте репозиторій:**
    ```bash
    git clone https://github.com/fgfalll/generator.git
    cd document-generator
    ```

2.  **Створіть та активуйте віртуальне оточення (рекомендовано):**
    ```bash
    # Для Windows
    python -m venv venv
    venv\Scripts\activate

    # Для macOS/Linux
    python3 -m venv venv
    source venv/bin/activate
    ```

3.  **Встановіть необхідні бібліотеки:**
    ```bash
    pip install -r requirements.txt
    ```

4.  **Запустіть програму:**
    ```bash
    python main.py
    ```

## Інструкція з використання

1.  **Крок 1: Завантаження даних**
    -   На панелі **"Головна"** або на стартовому екрані натисніть "Виберіть Excel файл" (`.xlsx` або `.csv`).
    -   Виберіть потрібний аркуш. Дані з'являться у великій таблиці.

2.  **Крок 2: Трансформація та Фільтрація (вкладка "Дані")**
    -   Якщо у вас є колонки типу "ПІБ", натисніть **"Розділити"**, виберіть пробіл як роздільник і задайте нові імена колонок.
    -   Для фільтрації непотрібних записів натисніть **"Фільтри"**. Додайте правила (наприклад, "Статус" дорівнює "Активний") та натисніть "Застосувати". У заголовку відфільтрованої колонки з'явиться лійка.
    -   Лівий клік по заголовку таблиці відкриває швидке меню перейменування чи дублювання колонки.

3.  **Крок 3: Співставлення (вкладка "Головна")**
    -   Натисніть **"Співставлення"** щоб прив'язати колонки таблиці до змінних (тегів) у вашому Word-шаблоні.
    -   Або скористайтеся **"Авто-маппінгом"**, щоб програма автоматично з'єднала колонки з однаковими назвами.

4.  **Крок 4: Шаблони та Бали**
    -   Виберіть потрібні шаблони `.docx` у списку праворуч.
    -   Якщо потрібна генерація чисел прописом — активуйте і налаштуйте **"Додати бали з таблиці"**.

5.  **Крок 5: Генерація**
    -   Натисніть **"Створити документи"** на бічній панелі. Програма згенерує файли у вибрану вами директорію!

## Структура Проєкту

```text
/document-generator
|
|-- /Приклади/             # Папка для шаблонів .docx
|   |-- example_template.docx
|
|-- main.py                # Головний файл для запуску
|-- ui.py                  # Модуль головного вікна, Ribbon, контекстні меню
|-- backend.py             # Основна логіка: обробка файлів, генерація Word
|-- column_mapper.py       # Логіка вікна співставлення (Mappings)
|-- score_mapper_dialog.py # Логіка вікна налаштування балів та прописів
|-- theme_manager.py       # Менеджер тем оформлення
|-- settings_dialog.py     # Вікно налаштувань
|-- requirements.txt       # Список актуальних залежностей
|-- README.md              # Цей файл
```
